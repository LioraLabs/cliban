# Packaging

Downstream package definitions for cliban. Both consume the prebuilt tarballs
from the [releases page](https://github.com/LioraLabs/cliban/releases), so
neither needs a Rust toolchain on the user's machine.

Neither is edited by hand. Checksums come from the release's own `SHA256SUMS`,
via [cook](https://github.com/LioraLabs/cook) — see the [`Cookfile`](../Cookfile).

## Cutting a release

```sh
cook bump 0.3.0                 # rewrite every version claim, refresh the lock
cook check                      # version sync, installer lint, tests, clippy
git commit -am "chore: v0.3.0"
cook release 0.3.0              # tag + push; CI builds and publishes the tarballs
```

Then, once the Release workflow is green:

```sh
cook tap 0.3.0        # regenerate the Homebrew formula, push the tap
cook aur 0.3.0        # refresh the PKGBUILD checksums
cook publish          # push all five crates to crates.io
cook smoke-install    # install from the live release into a sandbox and verify
```

## Homebrew

The tap is [LioraLabs/homebrew-tap](https://github.com/LioraLabs/homebrew-tap)
(`Formula/cliban.rb`), generated by `gen_formula.py` in that repo. `cook tap
<version>` clones it, regenerates, and pushes — it is a no-op if the formula is
already current.

Verify from a Mac, which is the half this project cannot test locally:

```sh
brew update && brew reinstall cliban && cliban --version
```

## AUR

`aur/PKGBUILD` builds `cliban-bin` for x86_64 and aarch64. `cook aur <version>`
fills both `sha256sums_*` arrays from the release.

Publishing is manual: it needs an AUR account whose SSH key is registered at
<https://aur.archlinux.org/account>.

```sh
cd packaging/aur
makepkg --printsrcinfo > .SRCINFO
makepkg -si                        # optional: build and install locally first

git clone ssh://aur@aur.archlinux.org/cliban-bin.git /tmp/cliban-bin
cp PKGBUILD .SRCINFO /tmp/cliban-bin/
cd /tmp/cliban-bin && git commit -am "upgpkg: cliban-bin 0.3.0-1" && git push
```

`.SRCINFO` is generated, so it is not tracked here — the AUR repo is the only
place it needs to exist.
